## Instalación y Ejecución

### Prerrequisitos
- **Node.js** 
- **Angular CLI** 
- **Java Runtime Environment (JRE / JDK)** para ejecutar la API local

### Pasos para levantar el proyecto

1. **Clonar el repositorio y el backend:**
   ```bash
   git clone https://github.com/avdeloya13/TiendaUNAM.git
   cd TiendaUNAM
   ```

2. **Levantar el servidor de la API REST:**
   Navegar a la carpeta de la API e iniciar el servicio de backend ejecutable de Java:
   ```bash
   cd api-dwf2025-1/api
   java -jar dwf-api-3.0.0.jar
   ```

3. **Instalar dependencias del Frontend:**
   Abrir una nueva terminal, navegar al directorio del cliente Angular e instalar los módulos necesarios:
   ```bash
   cd TiendaUNAM/TiendaOnlineUNAM
   npm install
   ```

4. **Ejecutar la aplicación web:**
   Levantar el servidor local de desarrollo de Angular para abrir la tienda en el navegador:
   ```bash
   ng serve
   ```
